# サンプルの素材を差し替える

素材の生成元は`tools/assets.py`です。変更後に`mcd.cmd build`または`make all`を実行すると、
画像・ADPCM・CD-DAとディスクを再生成します。`build/`と`dist/`の生成物を直接編集せず、
変換処理と元の素材を管理することで、別PCでも再構築できます。

現在のブリッジは次の独自コンテナを読みます。SGDK ResCompの出力や、任意のADPCM WAVを
そのまま読み込む形式ではありません。複数バイト整数は、WAVを除きビッグエンディアンです。

## 画像: IMAGE.MIM / MIMG

| バイト位置 | 型・長さ | 内容 |
|---|---|---|
| 0 | 4バイト | ASCII `MIMG` |
| 4 | u16 | 横のタイル数。現在は40固定 |
| 6 | u16 | 縦のタイル数。現在は28固定 |
| 8 | u16 | タイル数N。1〜1120 |
| 10 | u16 | 予約領域。0 |
| 12 | u16 × 16 | メガドライブのCRAM形式の16色パレット |
| 44 | N × 32バイト | 8×8・4bppのタイル画素 |
| 44 + N × 32 | u16 × 1120 | 40×28のタイルマップ。各値は0〜N−1 |

タイル内の画素は左から右、上から下の順です。1バイトの上位4ビットが左側の画素、
下位4ビットが右側の画素です。タイルマップも左から右、上から下の順です。
パレットは`0x0BGR`の各色成分に偶数値0〜Eを使用します。属性・反転ビットはマップに含めません。

ファイル全長は正確に`44 + N * 32 + 2240`バイトです。サンプルは重複をまとめず1120タイルを
格納するため38124バイトになります。`VDP_drawImage()`はパレット0、VRAMのタイル番号1以降を
使用し、指定したPlane AまたはBへ配置します。入力ポインタは偶数アドレスが必要です。

## 圧縮音声: SOUND.IMA / MIMA

| バイト位置 | 型・長さ | 内容 |
|---|---|---|
| 0 | 4バイト | ASCII `MIMA` |
| 4 | u16 | 形式バージョン。1 |
| 6 | u16 | サンプルレート。現在は22050固定 |
| 8 | u32 | 展開後サンプル数S。1〜65534 |
| 12 | s16 | 初期predictor |
| 14 | u8 | 初期ステップインデックス。0〜88 |
| 15 | u8 | 予約領域。0 |
| 16 | ceil(S / 2)バイト | IMA/DVI 4ビットADPCMペイロード |

1バイトにつき**下位ニブルから先に**デコードします。各ニブルが1出力サンプルです。
初期predictorそのものを別の先頭サンプルとして出力しません。Sが奇数の場合は末尾の上位ニブルを無視します。
ファイル全長は正確に`16 + ceil(S / 2)`バイトです。

`ima_encode()`は符号付き16ビット相当のモノラルサンプル列を受け取り、初期predictor=0、
ステップインデックス=0のペイロードを生成します。サンプルは2秒・44100サンプルです。
再生前にSub CPUがRF5C164の符号・絶対値形式へ展開し、PCM Wave RAMへ置きます。
末尾の無音ループ用に2バイトを予約します。長い音声のストリーミングや複数音声の同時保持は未対応です。

## CD-DA: track02.wav

44.1 kHz・16ビット整数・ステレオの非圧縮WAVを使用します。現在の生成物は先頭2秒の無音と
8秒の検査音で、左330 Hz・右550 Hzです。CUEの`INDEX 00`が無音の先頭、`INDEX 01 00:02:00`が
音声トラックの開始です。差し替える際も、このCUEを使用するなら先頭2秒を維持してください。

CD-DAはISO内のファイルとして再生しません。CUEがWAVをオーディオトラック2として参照します。
CUE・ISO・WAVを同じディレクトリに置き、CUEを開きます。ブリッジが受け付ける音声トラック番号は現在2のみです。

## CD上のファイル登録

`tools/disc.py`が`build/disc/`をISO9660のルートへ格納します。大文字の8.3形式を使用し、
Sub側の`src/sub/kernel.c`にあるアセットIDとファイル名テーブルを対応させます。
`IPX.MMD`は起動するMainプログラムなので保持してください。
ディスク構成とAPIの上限は[構成資料](architecture.md)を参照してください。
